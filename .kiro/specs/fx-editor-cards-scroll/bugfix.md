# Bugfix Requirements Document

## Introduction

В FX редакторе на вкладке "ОБЪЕКТЫ" карточки объектов (overlay objects) не отображаются корректно и отсутствует возможность прокрутки списка карточек. Когда пользователь добавляет несколько объектов, карточки либо выходят за пределы видимой области, либо накладываются друг на друга, либо не помещаются в контейнер. Это делает невозможным управление объектами, когда их количество превышает размер экрана.

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN пользователь открывает вкладку "ОБЪЕКТЫ" в FX редакторе с несколькими добавленными объектами THEN карточки объектов не отображаются корректно в контейнере `.fxe-ov-list`

1.2 WHEN количество карточек объектов превышает высоту видимой области контейнера THEN система не предоставляет возможность прокрутки списка карточек

1.3 WHEN карточки объектов выходят за пределы видимой области THEN пользователь не может получить доступ к скрытым карточкам для их редактирования или удаления

1.4 WHEN контейнер `.fxe-ov-list` имеет `overflow-y:auto` но родительский контейнер `.fxe-ov-left` не имеет правильных ограничений высоты THEN вертикальная прокрутка не активируется

### Expected Behavior (Correct)

2.1 WHEN пользователь открывает вкладку "ОБЪЕКТЫ" в FX редакторе с любым количеством объектов THEN система SHALL корректно отображать все карточки объектов в контейнере `.fxe-ov-list` с правильной структурой и форматированием

2.2 WHEN количество карточек объектов превышает высоту видимой области контейнера THEN система SHALL автоматически активировать вертикальную прокрутку для списка карточек

2.3 WHEN карточки объектов выходят за пределы видимой области THEN система SHALL позволять пользователю прокручивать список вниз и вверх для доступа ко всем карточкам

2.4 WHEN контейнер `.fxe-ov-list` содержит карточки THEN система SHALL правильно применять CSS-свойства `flex:1`, `overflow-y:auto`, и `min-height:0` для обеспечения прокрутки

### Unchanged Behavior (Regression Prevention)

3.1 WHEN пользователь взаимодействует с карточками объектов (сворачивание, редактирование параметров, удаление) THEN система SHALL CONTINUE TO корректно обрабатывать все действия пользователя

3.2 WHEN пользователь добавляет новые объекты или текстовые элементы THEN система SHALL CONTINUE TO создавать новые карточки и отображать их в списке

3.3 WHEN пользователь переключается между вкладками "ТЕКСТ" и "ОБЪЕКТЫ" THEN система SHALL CONTINUE TO сохранять состояние карточек (свёрнутые/развёрнутые)

3.4 WHEN количество карточек помещается в видимую область без прокрутки THEN система SHALL CONTINUE TO отображать карточки без полосы прокрутки

3.5 WHEN пользователь изменяет параметры объектов (позиция, размер, эффекты, слой) THEN система SHALL CONTINUE TO обновлять превью объектов на правой панели

3.6 WHEN пользователь использует кнопки z-order (⬆/⬇) для изменения порядка объектов THEN система SHALL CONTINUE TO корректно перемещать объекты в списке
